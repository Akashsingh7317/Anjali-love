Anjali Babu - Birthday Website
==============================

Kaise kholein:
  1. index.html ko double-click karke browser (Chrome) mein kholo.
  2. Password: 2026
  3. Music ke liye right-bottom wala 🎵 button dabao (unlock ke baad apne aap start hota hai).

Phone par bhejne ke liye:
  - Poora "anjali" folder zip karke bhejo (index.html + photos/ + three.min.js saath mein hone chahiye).
  - Ya kisi free hosting (Netlify Drop / GitHub Pages / Vercel) par folder upload karke link share karo.

Kuch badalna ho to index.html kholo aur upar "CONFIG" section mein:
  - name      : naam
  - password  : password
  - letter    : letter ka text
  - reasons   : "Why You're Special" cards
  - signature : letter ke neeche ka naam

Photos badalni ho: photos/ folder mein 1.jpg, 2.jpg ... rakho aur CONFIG mein photoCount set karo.
