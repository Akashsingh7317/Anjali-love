Anjali - Birthday Surprise Website
==================================

Kaise kholein:
  1. index.html ko Chrome mein kholo (ya start-server.bat chala kar http://localhost:8765 kholo).
  2. Intro chalega: digital clock -> matrix waveform -> glowing particles -> "Happy Birthday, Anjali".
     (SKIP button se skip kar sakte ho.)
  3. Password: 2026
  4. Music right-bottom (phone par right-top) ke 🎵 button se on/off hota hai.

Sections:
  - Hero (naam par hover/click karo)
  - 3D Cake: drag karke ghumao, "Blow the Candles" dabao (ya mic mein phoonk maaro)
  - Pop the Balloons: har balloon pop karne par ek photo reveal hoti hai
  - Beautiful Memories (3D ring) + Wall of Smiles (3D hover)
  - Why You're Special (flip cards)
  - Under the Stars: envelope kholo, letter type hota hai, "Read aloud" se sunao
  - Finale: Celebrate dabao -> digital fireworks + naam aasmaan mein

Pixie (3D guide): left-bottom mein hai. Uske buttons se kisi bhi section par jump karo,
  🔊 button se voice on/off.

Edit karna ho: index.html mein upar CONFIG section hai
  name, password, song, letter, reasons, signature, photoCount.

Photos: photos/ (full size, lightbox ke liye) aur photos/t/ (thumbnails, galleries ke liye).
  Nayi photo add karni ho to dono folder mein same number ke naam se rakho aur photoCount badhao.

Phone par bhejne ke liye poora folder zip karo: index.html, three.min.js, anjali-song-v3.mp3, photos/
